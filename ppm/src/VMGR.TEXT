  A plain unit, compiled on its own and USE'd by PASCALPR.

  program cannot call them (error 104). Every procedure
  here is lex 1, and procedure 1 returns with RNP, which
  is the unit initialisation UNITBODY builds (finding 232).

  The interface is a prefix. GETTEXT numbers headings from
  2 in the order written, and an implementation-only
  procedure is numbered after the whole interface. The
  menu and VOLUMEMA call 2..9, 12..18 and 20..24, so those
  numbers have to be interface headings. 10, 11 and 19 sit
  in the same prefix, so they are headings too. Nothing
  outside the unit calls past 24; later procedures stay
  out of the interface until one of them does.

  Empty bodies. The point of this file is the procedure
  numbers, not the code. }
