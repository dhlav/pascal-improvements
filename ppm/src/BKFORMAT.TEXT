;---------------------------------------------------
; BKFORMAT -- BACKUP.DATA, the Disk II formatter
; overlay BACKUP loads at 01300. DOBACKUP LOADCODE
; BLOCKREADs the three blocks onto the heap after
; RELEASE to 4864, then FORMDISK indexes a table and
; JSR 1300. Same 1082-byte formatter as ASMFORMAT
; (FORMATTER.DATA blocks 0-2, origin 03D00) with
; origin 01300 and STOR0 010 instead of 0E.
;
; Labels keep the F3Dxx/F40xx names from ASMFORMAT;
; they are names, not addresses. DELAY and the
; STOR*/TMP* cells are .EQU at origin+offset so the
; assembler's stale tail (block 2 bytes 024A-03FF
; repeating block 1) holds resolved 017xx words,
; the same evidence FORMATTER.DATA has at 041xx.
;
; Apple's 1.3 assembler writes the three blocks;
; BACKUP.DATA is those blocks (codefile block 0 is
; the dictionary and is dropped).
;---------------------------------------------------
