{ ASSMBLER -- Apple Pascal 1.3 SYSTEM.ASSMBLER, reconstructed.

  Seven segments and 95 procedures. Six of them are Apple's own
  1.3 compiler output (SEGINFO 6); the seventh, PASCALIO, is a
  five-procedure cut-down of the library unit that exists on no
  disk in the set and cannot be rebuilt from anything that does
  -- see finding 235b, and expect that one segment to differ.

  The shape is SYSTEM.COMPILER's, not an ordinary program's.
  TLA.1 ends RBP 0, which BODY3 emits only for a procedure at
  PFLEV 0, and it has no NOP pair at its head, which BODY1 emits
  for every program main. So this is a (*$U-*) compilation whose
  first SEGMENT PROCEDURE is TLA -- segment 1 -- with (*$NS 7*)
  moving the counter so the five nested ones land on 7 to 11
  (finding 235a).

  TLA's two parameters are the pair SYSTEM.PASCAL enters segment
  1 with, and the assembler reads neither; its own globals start
  at word 3 for that reason, not because anything reserved them.

  Procedure bodies are stubs for now. They are here to hold
  their NUMBERS, which declaration order fixes and which every
  CGP, CLP and CXP in someone else's body has to agree with. The
  numbering constraint that shapes the whole file is TLA's:
  procedure 4's nested child is 23, so headings 2 through 22
  must all be claimed before 4's body is compiled. }

{ (*$U-*) sets IOCHECK := NOT SYSCOMP, so it turns I/O checking OFF, and
  the binary says Apple turned it back on: 184 of its OS I/O calls carry
  the CSP 0 that only IOCHECK emits. The ones that do not are in an
  (*$I-*) region of their own -- TLA.29 and INITIALI.4, .5 and .6 whole,
  and one statement each in TLA.12 and PROCEND.9 -- and every one of them
  tests IORESULT itself, TLA.12 and TLA.29 by calling TLA.5 next.
  TLA.1's six bare calls are not evidence
  either way: BODY2 and BODY3 generate the FINIT/FCLOSE sweeps and never
  put a check on them. }

{ No USES PASCALIO, and none is possible or needed. SEEK is a STANDARD
  PROCEDURE: COMPINIT's ENTSTDNAMES registers it and ROUTINE's GETPUTETC
  emits `GENNR(31, 2)` for it, which is `CXP 31,2` with the segment number
  hard-coded. So the five FSEEK calls in PROCEND and PRINTERR are sugar,
  exactly like WRITE, and are written `SEEK(F, N)`.

  A USES was tried and is a dead end for a second reason besides: the
  interface text PASCALIO carries declares `PROCEDURE FSEEK(VAR F: FIB...)`
  and re-parsing it needs a type named FIB in scope, which this program has
  no reason to declare. Apple's compiler reads the unit (`PASCALIO [16472
  words]`) and then stops on error 104 at the interface's own first line. }

    of the difference and it is VERIFIED SOURCE FACT (BODYPART.text): a
    value in 0..127 is one byte, anything else is `LDCI` plus `ABS(IVAL)`
    in two bytes plus `NGI` when negative. So a constant -1 reaching
    GENLDC gives `LDCI 1 | NGI`, which is what TLA.27 has, while writing
    `-1` in an expression loads 1 with `SLDC` and negates -- which is
    what ASSEMBLE.26's `SPCLSTIX <> -1` has, and that one is exact. The NAME is
    SPECULATION; that Apple declared a constant here is not. }

  SEGMENT PROCEDURE PRINTERROR(X1: INTEGER);  { seg 11  .1  2/728 }
    { 364 local words. The file is 321 of them -- FILESIZE 300 plus a
      21-word window, which is what FINIT's third argument says, and 21
      words is a STRING[40]. MARKP is the next, from `LLA 323 | CSP 32`.
      The remaining 42 are declared and never touched by this procedure,
      which is the only one in the segment, so nothing says what they
      are. }
    VAR
      ERRFILE: FILE OF STRING[40];
      MARKP: ASMRECP;
      UNUSED: PACKED ARRAY [0..83] OF CHAR;

  BEGIN
    (*$I-*)
    RESET(ERRFILE, '%6502.ERRORS');
    MARK(MARKP);
    (*$I+*)
    IF IORESULT <> 0 THEN T22(X1, TRUE)
    ELSE
      BEGIN
        SEEK(ERRFILE, X1);
        GET(ERRFILE);
        IF G12 THEN
          BEGIN
            WRITELN(G73);
            WRITE(G73, LINEBUF);
            WRITELN(G73);
            WRITE(G73, ERRFILE^);
            WRITELN(G73);
            G32 := G32 + 3
          END;
        IF NOT (NOPRINT AND G12) THEN
          BEGIN
            WRITELN;
            WRITE(LINEBUF);
            WRITELN;
            WRITE(ERRFILE^);
            WRITELN
          END
      END
    { No CLOSE here: the single `LLA 2 | SLDC 0 | CXP 0,6` Apple ends with
      carries no `CSP 0`, and BODY3 generates exactly that for every FILE
      declared in a block. An explicit CLOSE would be checked, and would
      be followed by the generated one as well. }
  END;


{ Bodies, in Apple's own physical order -- which is enter_ic order,
  and which is also the order the numbering forces: a parent's
  children are emitted before it, so 4 claims 23, then 15 claims
  24-25, then 14 claims 26-28, and only then can 29 be declared. }

  { Reports an error that has no source line to point at -- the listing
    gets the line buffer, the error number, and when X2 is set the reason
    the error file itself could not be opened. The console copy is
    suppressed only when the listing is already going there. V3 is the
    number of lines the listing gained, 3 or 4. }
  PROCEDURE T22;                              { .22  4/2 }
    VAR
      V3: INTEGER;
  BEGIN
    IF G12 THEN
      BEGIN
        WRITELN(G73);
        WRITE(G73, LINEBUF);
        WRITELN(G73);
        WRITE(G73, 'ERROR #');
        WRITE(G73, X1:4);
        WRITELN(G73);
        IF X2 THEN
          BEGIN
            WRITE(G73, '"', '6502', '.ERRORS" file not found');
            WRITELN(G73);
            V3 := 4
          END
        ELSE V3 := 3;
        G32 := G32 + V3
      END;
    IF NOT (NOPRINT AND G12) THEN
      BEGIN
        WRITELN;
        WRITE(LINEBUF);
        WRITELN;
        WRITE('ERROR #');
        WRITE(X1:4);
        WRITELN;

          BEGIN
            WRITE('"', '6502', '.ERRORS" file not found');

      END

  PROCEDURE T21;                              { .21  0/0 }
  BEGIN
    WRITELN('Fatal error.  Cannot continue.')
  END;

  { The error reporter everything else calls. PRINTERROR needs 1800
    words to read its message file, so a tight heap gets the bare number
    from TLA.22 instead. Then the three-way prompt: space goes on, escape
    leaves, E sets the Editor up on the line that failed and leaves.

    Errors 47..60 are the ones there is no point continuing from, so they
    take the escape path whatever was typed. The work symbol file is
    RESET and purged on the way out of both, which is how the Editor is
    made to re-open it, and neither the open nor the close is checked. }
  PROCEDURE T2;                               { .2  2/2 }
    VAR
      CH: CHAR;
  BEGIN
    G31 := G31 + 1;
    IF MEMAVAIL > 1800 THEN PRINTERROR(X1)
    ELSE T22(X1, FALSE);
    WRITE(CHR(7));
    WRITE('<sp>(continue), <esc>(terminate), E(dit');
    REPEAT
      READ(KEYBOARD, CH)
    UNTIL (CH = ' ') OR (CH = 'e') OR (CH = 'E') OR (CH = CHR(27));
    IF (CH = CHR(27)) OR ((X1 >= 47) AND (X1 <= 60)) THEN
      BEGIN
        (*$I-*)
        RESET(G1135, G590);
        CLOSE(G1135, PURGE);
        (*$I+*)
        IF CH = ' ' THEN T21;
        EXIT(TLA)
      END;
    IF (CH = 'E') OR (CH = 'e') THEN
      BEGIN
        { NAMEDSRC says the source is the file the operator named, so the
          position to edit is the one SAVED for the work file; otherwise
          it is where we are now. }
        IF NAMEDSRC THEN
          BEGIN
            USERINFO.ERRSYM := ERRCOL;
            USERINFO.ERRBLK := SAVBLK - 2
          END
        ELSE
          BEGIN
            USERINFO.ERRSYM := SRCPOS;
            USERINFO.ERRBLK := FILEBLK - 2
          END;
        USERINFO.ERRNUM := 500;
        (*$I-*)
        RESET(G1135, G590);
        CLOSE(G1135, PURGE);
        (*$I+*)
        EXIT(TLA)
      END;
    T8;
    IF G12 AND (G32 MOD PAGESIZE < 4) THEN T9
  END;

  { The byte swapper, and it is exactly that: read the word in, write
    its low byte out as the high one and its high byte as the low. Two
    of its four local words are placeholders. Everything that called
    this -- PROCEND.2's `IF G57 <> FALSE`, INITIALI.4's `IF V3`,
    ASSEMBLE.3's `IF FALSE` -- was reading it right. }
  FUNCTION T3;                                { .3  6/8 }
    VAR
      V4: WORDSWAP;
      V6: WORDSWAP;
  BEGIN

    V4.LOWBYTE := V6.HIBYTE;
    T3 := V4.HWORD
  END;

  { Emits the one or two bytes an operand assembled to, at X2 in the
    code buffer, and lists them. X1 is the five-word record the operand
    parser filled in: FLAG says a single byte was asked for, F1 is the
    value and F2 the location to report if it will not fit.

    Locals 9 and 10 are declared and never touched, the same two-word
    overshoot TLA.3 has (finding 257b). They are at the end of the
    frame here, but a temp cannot explain them either: nothing in the
    body opens a WITH or a FOR. }
  PROCEDURE T4;                               { .4  4/16 }
    VAR
      V3: FIVEREC;
      V8: WORDSWAP;
      PAD10: INTEGER;

    { One listing line: the location, then the bytes. A word is
      printed high nibble first, so listing two bytes in the order they
      sit in memory means swapping the word; a single byte is printed as
      it is. X1 says which, and is all the `IF X1` arm needs -- the
      `IF FALSE` above it is dead, like T4's own (finding 258a). }
    PROCEDURE T23(X1: BOOLEAN);               { .23  2/0 }
    BEGIN
      T11(V3.F2, FALSE);
      WRITE(G73, '* ');
      IF LISTHIFIRST THEN T11(V3.F1, X1)
      ELSE IF X1 THEN T11(V3.F1, X1)
      ELSE T11(T3(V3.F1), X1);
      WRITELN(G73);
      G32 := G32 + 1;
      IF G32 MOD PAGESIZE = 0 THEN T9
    END;

  BEGIN
    V3 := X1;
    V8.HWORD := V3.F1;
    IF V3.FLAG THEN
      BEGIN
        IF (V8.HWORD > 127) OR (V8.HWORD < -128) THEN
          BEGIN
            V8.HWORD := V3.F2;
            WRITE('Location ');
            WRITE(G2120[V8.HEX1]);
            WRITE(G2120[V8.HEX2]);
            WRITE(G2120[V8.HEX3]);
            WRITE(G2120[V8.HEX4]);
            WRITELN;
            T2(2)
          END
        ELSE
          BEGIN
            SRCBUF^[X2] := CHR(V8.LOWBYTE);
            IF G12 AND G56 THEN T23(TRUE)
          END
      END
    ELSE
      BEGIN
        { `SLDC 0 | FJP`: a constant-false guard over a statement
          that can therefore never run. The compiler DOES fold `NOT` of
          a boolean constant (`BODYPART`'s NOTSY arm), so this could
          equally be a named flag, or `NOT` a named flag, and the bytes
          cannot tell which -- nor which sense, since the two dead
          guards here and in T23 read as opposites (finding 258a). }
        IF HIBYTEFIRST THEN V8.HWORD := T3(V8.HWORD);
        SRCBUF^[X2] := CHR(V8.LOWBYTE);
        SRCBUF^[X2 + 1] := CHR(V8.HIBYTE);
        IF G12 AND G56 THEN T23(FALSE)
      END
  END;

  { Copies the current source line out of the 1024-byte input window into

  PROCEDURE T15;                              { .15  2/6 }
    { Three local words, and the same shape as TLA.14's five: a two-word
      number whose address goes to T13, and a mode word T24 sets to 3.
      Word 3 is the number's second word (finding 259a). }
    VAR
      V2: WORDSWAP;
      V4: INTEGER;

    { Flushes one symbol's reference block to the linker-info file when
      it fills up -- seven references make a record, then the block is
      cleared and the count restarts.

      Two VAR parameters and a value one. The first is the running count
      the caller keeps (`SLDL 3 | SIND 0` to read, `SLDL 3 | ... | STO`
      to write) and the second the seven-word block it indexes. A VAR
      formal is one word holding an address, which is why three
      parameters come to PARAM SIZE 6 with a seven-word array among
      them. }
    PROCEDURE T25(VAR X1: INTEGER; VAR X2: SEVEN;

              G1135^.KEY0 := X3;
              G1135^.REFS := X2;
              PUT(G1135);

              X1 := 0
            END;

        END

    V2.HWORD := X1;

      source order -- and every arm ends by handing the operand to T25,
      which is what files the reference. }
    CASE RELOCATE.W0 OF

      0: BEGIN

               ELSE NEW(CURFIVE)
             END;

                   END
         END;

           IF RELOCATE.W5^.A5 <> 27 THEN
             BEGIN
               RELOCATE.W5^.A7 := RELOCATE.W5^.A7 + 1;
               NEW(G628);
               G628^.OFFSET := EMITMODE - 512;
               G628^.NEXT := RELOCATE.W5^.A8;
               RELOCATE.W5^.A8 := G628
             END;
           CASE RELOCATE.W5^.A5 OF
             28, 30: T25(G46, G636, 3);
             31: T25(G47, G643, 2);
             27: ;
           END;
           IF RELOCATE.W4 = 27 THEN T25(G45, G629, 4)
         END
    END;
    RELOCATE := G598;
    T13(V2, V4, FALSE)
  END;

  PROCEDURE T14;                              { .14  6/10 }
    { Five local words: two two-word numbers and the kind TLA.26
      writes. Offsets 4, 6 and 8 are all pinned, by the nested TLA.26,
      TLA.27 and TLA.28 that read and write them, and they only land
      there if a number is two words wide. }
    VAR
      V4: WORDSWAP;
      V6: WORDSWAP;
      V8: INTEGER;

    { Fills in the relocation record at CURFIVE for the operand just
      assembled. X2 says the operand is a word; a byte takes the ELSE
      arm and V8 -- the kind the caller will write into the linker
      information -- is 3 rather than 1 or 2.

      Two of the conditions here are compile-time constants Apple's
      compiler did not fold, the same configuration switches TLA.27 has
      and spelled the same way. The four-term one is a bit mask, not a
      boolean: LAND takes BOOLEAN operands only (error 134 otherwise),
      so -1 and -2 reach it through ODD's free cast. }
    PROCEDURE T26;                            { .26  0/0 }
    BEGIN
      CURFIVE^.F3 := EMITMODE;
      CURFIVE^.F2 := LOCCTR;
      CURFIVE^.HIB := ORD(X3);
      IF X2 THEN
        BEGIN
          IF TRUE THEN V8 := 2
          ELSE V8 := 1;
          IF (TRUE AND ODD(MINUS1)) OR (ODD(MINUS2) AND FALSE) THEN
            CURFIVE^.F3 := EMITMODE + 1;
          CURFIVE^.FLAG := TRUE;
          IF RELOCATE.W4 = 35 THEN CURFIVE^.F1 := RELOCATE.W3 - G20
        END
      ELSE
        BEGIN
          V8 := 3;
          CURFIVE^.FLAG := FALSE;
          IF RELOCATE.W4 = 35 THEN CURFIVE^.F1 := X1 - G20
        END
    END;

    PROCEDURE T27;                            { .27  0/0 }
    { Two conditions here are compile-time constants that Apple's compiler
      did not fold, and they read as configuration flags: `LDCI 1 | NGI`
      is a declared CONST of -1 handed to LAND, which only ODD's free
      cast (finding 231) can do, and `SLDC 1 | FJP` is a literal TRUE around
      the choice of which byte of V6 receives V4's low byte -- a byte
      order switch. The BYTES are Apple's; how Apple spelled the two
      constants is SPECULATION. }
    BEGIN
      IF ODD(MINUS1) AND X3 THEN V4.HWORD := V4.HWORD DIV 2;
      IF (V4.HWORD >= -128) AND (V4.HWORD <= 127) THEN
        BEGIN
          IF TRUE THEN V6.HIBYTE := V4.LOWBYTE
          ELSE V6.LOWBYTE := V4.LOWBYTE
        END
      ELSE T2(20)
    END;

    PROCEDURE T28;                            { .28  0/0 }
    BEGIN
      IF X2 THEN
        BEGIN
          IF RELOCATE.W4 = 35 THEN V4.HWORD := RELOCATE.W3 - G20
          ELSE V4.HWORD := RELOCATE.W3;
          T27
        END
      ELSE
        IF RELOCATE.W4 = 35 THEN V6.HWORD := X1 - G20
    END;

  BEGIN
    V8 := 0;
    V6.HWORD := X1;
    { Arms in SOURCE order, which is physical order, not label order
      (finding 245a). }
    CASE RELOCATE.W0 OF
      4: IF X2 THEN
           BEGIN
             V4.HWORD := RELOCATE.W3;
             T27
           END;
      3: T28;
      0: IF RELOCATE.W1 THEN
           BEGIN
             T26;
             CURFIVE^.F4 := G691[RELOCATE.W2].LREFS;
             G691[RELOCATE.W2].LREFS := CURFIVE;
             IF G657 <> NIL THEN
               BEGIN
                 CURFIVE := G657;
                 G657 := G657^.F4
               END
             ELSE NEW(CURFIVE)
           END
         ELSE T28;
      1: CASE RELOCATE.W5^.A5 OF
           1, 32, 33, 35: T28;
           26, 36: BEGIN
                     T26;
                     CURFIVE^.F4 := RELOCATE.W5^.A7P;
                     RELOCATE.W5^.A7P := CURFIVE;
                     IF G657 <> NIL THEN
                       BEGIN
                         CURFIVE := G657;
                         G657 := G657^.F4
                       END
                     ELSE NEW(CURFIVE)
                   END
         END;
      2: BEGIN
           IF G12 THEN
             BEGIN
               WRITELN(G73);
               WRITE(G73, RELOCATE.W5^.ANAME)
             END;
           IF NOT (NOPRINT AND G12) THEN
             BEGIN
               WRITELN;
               WRITE(RELOCATE.W5^.ANAME)
             END;
           T2(21)
         END
    END;
    RELOCATE := G598;
    T13(V6, V8, FALSE)
  END;

  { Reads the next two blocks of source into the 1024-byte window and
    starts a line from the head of it. NAMEDSRC says the source is still the
    file the operator named; when it runs out, the INCLUDE stack is
    popped back to the work file -- SAVBLK and ERRCOL are the saved block and
    offset -- and NAMEDSRC goes false for the rest of the assembly. The work
    file it reads is WORKSYM, the .TEXT: `LOD 2,9`, one past the
    WORKCODE every already-exact BLOCKWRITE in PROCEND uses, because
    the two share a clause and a clause's names descend. If there
    is nothing to pop, error 36 and out of the assembler entirely.

    This whole procedure is one of the four with IOCHECK off: its
    BLOCKREADs and its CLOSE carry no CSP 0, and the option is lexical,
    so it is turned back on immediately after (finding 256e). }
  (*$I-*)
  PROCEDURE T29;                              { .29  0/0 }
  BEGIN
    LINEBUF := G488;
    LINEPOS := 0;
    IF NAMEDSRC THEN G40 := BLOCKREAD(G1095, SRCWIN, 2, FILEBLK)
    ELSE G40 := BLOCKREAD(USERINFO.SYMFIBP^, SRCWIN, 2, FILEBLK);
    SRCPOS := 0;
    FILEBLK := FILEBLK + G40;
    IF G40 = 0 THEN
      BEGIN
        IF NAMEDSRC THEN
          BEGIN
            FILEBLK := SAVBLK;
            SRCPOS := ERRCOL;
            G40 := BLOCKREAD(USERINFO.SYMFIBP^, SRCWIN, 2, FILEBLK - 2);
            NAMEDSRC := FALSE;
            CLOSE(G1095);
            G390 := G374
          END
        ELSE
          BEGIN
            T2(36);
            T21;
            EXIT(TLA)
          END
      END;
    T5(TRUE);
    LINEPOS := SCAN(102, = CHR(13), SRCWIN[SRCPOS]);
    G16 := SCAN(1024, = CHR(0), SRCWIN[0]);
    IF LINEPOS < 102 THEN MOVELEFT(SRCWIN[SRCPOS], LINEBUF, LINEPOS)
    ELSE MOVELEFT(SRCWIN[SRCPOS], LINEBUF, 102)
  END;
  (*$I+*)

  { Reads the next character of the statement into ASMCH, out of whichever
    of the three sources CHSOURCE names: a macro body being expanded (0), a
    macro's actual-parameter text (1), or the source window itself (2).
    The three arms are the same shape -- step the position unless ADVANCE
    says the last call left it stepped already, take the character, and
    keep the line buffer LINEBUF in step so the listing shows what was read.

    FOLDCAS makes the scanner fold case and collapse runs of blanks; INMACDEF
    suppresses that while a macro is being DEFINED, where the text has to
    go in as typed. A DLE in the text is the blank-compression pair the
    listing writes, and DLEZERO remembers whether its count was zero. }
  PROCEDURE T16;                              { .16  0/2 }
    VAR
      V1: INTEGER;

    { Opens an INCLUDE level: X1 is the caller's own scan position, by
      VAR, and moves on past the digit that named the level. The rest
      walks the operand out of whichever buffer this level reads from --
      a macro buffer when there is a level above, the source window
      otherwise -- and a comma drops one field. Anything but a CR or a
      semicolon at the end means there was a file to push. }
    PROCEDURE T30(VAR X1: INTEGER);           { .30  2/4 }
      VAR
        V2: INTEGER;
        V3: INTEGER;
    BEGIN
      ASMCH := ORD(MACBUFP^[X1 + 1]);
      X1 := X1 + 2;
      IF (ASMCH < 49) OR (ASMCH > 57) THEN T2(22)
      ELSE
        BEGIN
          V3 := ASMCH - 49;
          V2 := G667[MACLEVEL - 1];
          IF MACLEVEL > 1 THEN
            BEGIN
              MACBUFP := MACBUFS[MACLEVEL - 1];
              WHILE (V3 <> 0) AND (MACBUFP^[V2] <> CHR(13)) DO
                BEGIN
                  IF MACBUFP^[V2] = ',' THEN V3 := V3 - 1;
                  V2 := V2 + 1
                END;
              V3 := SCAN(102, <> ' ', MACBUFP^[V2]);
              V2 := V2 + V3;
              ASMCH := ORD(MACBUFP^[V2]);
              IF (ASMCH = 13) OR (ASMCH = 59) THEN MACBUFP := MACBUFS[MACLEVEL]
            END
          ELSE
            BEGIN
              WHILE (V3 <> 0) AND (SRCWIN[V2] <> CHR(13)) DO
                BEGIN
                  IF SRCWIN[V2] = ',' THEN V3 := V3 - 1;
                  V2 := V2 + 1
                END;
              V3 := SCAN(102, <> ' ', SRCWIN[V2]);
              V2 := V2 + V3;
              ASMCH := ORD(SRCWIN[V2])
            END;
          IF (ASMCH <> 13) AND (ASMCH <> 59) THEN
            BEGIN
              CHSOURCE := 1;
              G679[MACLEVEL] := X1;
              MACLEVEL := MACLEVEL - 1;
              MACPPOS := V2
            END;
          ADVANCE := FALSE;
          T16
        END
    END;

  BEGIN
    CASE CHSOURCE OF
      0: BEGIN
           IF ADVANCE THEN
             BEGIN
               MACBPOS := MACBPOS + 1;
               LINEPOS := LINEPOS + 1
             END
           ELSE ADVANCE := TRUE;
           IF MACBUFP^[MACBPOS] = CHR(16) THEN
             BEGIN
               ASMCH := ORD(MACBUFP^[MACBPOS + 1]);
               DLEZERO := ASMCH - 32 = 0;
               IF LINEPOS < 101 THEN
                 BEGIN
                   LINEBUF[LINEPOS] := CHR(16);
                   LINEBUF[LINEPOS + 1] := CHR(ASMCH);
                   LINEPOS := LINEPOS + 2
                 END;
               MACBPOS := MACBPOS + 2
             END;
           ASMCH := ORD(MACBUFP^[MACBPOS]);
           IF ASMCH = 37 THEN
             BEGIN
               G26 := MACLEVEL;
               T30(MACBPOS)
             END
           ELSE IF (ASMCH = 32) AND FOLDCAS THEN
             BEGIN
               V1 := SCAN(102, <> ' ', MACBUFP^[MACBPOS]);
               IF LINEPOS + V1 < 102 THEN
                 BEGIN
                   FILLCHAR(LINEBUF[LINEPOS], V1, ' ');
                   LINEPOS := LINEPOS + V1 - 1
                 END;
               MACBPOS := MACBPOS + V1 - 1
             END
           ELSE IF ASMCH <> 13 THEN
             BEGIN
               IF LINEPOS < 102 THEN LINEBUF[LINEPOS] := CHR(ASMCH);
               IF ASMCH = 9 THEN ASMCH := 32
             END
         END;
      1: BEGIN
           IF ADVANCE THEN
             BEGIN
               MACPPOS := MACPPOS + 1;
               LINEPOS := LINEPOS + 1
             END
           ELSE ADVANCE := TRUE;
           IF MACLEVEL > 0 THEN ASMCH := ORD(MACBUFP^[MACPPOS])
           ELSE ASMCH := ORD(SRCWIN[MACPPOS]);
           IF (ASMCH = 37) AND (MACLEVEL > 0) THEN T30(MACPPOS)
           ELSE IF (ASMCH = 44) OR (ASMCH = 13) OR (ASMCH = 59) THEN
             BEGIN
               { End of one actual parameter: back over the blanks it
                 was padded with -- a NEGATIVE scan length scans
                 backwards -- and pop the level. }
               MACLEVEL := MACLEVEL + 1;
               IF MACLEVEL > 1 THEN
                 V1 := SCAN(-70, <> ' ', MACBUFP^[MACPPOS - 1])
               ELSE V1 := SCAN(-70, <> ' ', SRCWIN[MACPPOS - 1]);
               LINEPOS := LINEPOS + V1;
               MACBUFP := MACBUFS[MACLEVEL];
               IF MACLEVEL = G26 THEN CHSOURCE := 0
               ELSE MACPPOS := G679[MACLEVEL];
               ADVANCE := FALSE;
               T16
             END
           ELSE IF (ASMCH = 32) AND FOLDCAS THEN
             BEGIN
               REPEAT
                 IF LINEPOS < 102 THEN LINEBUF[LINEPOS] := ' ';
                 LINEPOS := LINEPOS + 1;
                 MACPPOS := MACPPOS + 1;
                 IF MACLEVEL > 0 THEN ASMCH := ORD(MACBUFP^[MACPPOS])
                 ELSE ASMCH := ORD(SRCWIN[MACPPOS])
               UNTIL ASMCH <> 32;
               ASMCH := 32;
               MACPPOS := MACPPOS - 1;
               LINEPOS := LINEPOS - 1
             END
           ELSE
             BEGIN
               IF LINEPOS < 102 THEN LINEBUF[LINEPOS] := CHR(ASMCH);
               IF ASMCH = 9 THEN ASMCH := 32
             END
         END;
      2: BEGIN
           IF ADVANCE THEN SRCPOS := SRCPOS + 1
           ELSE ADVANCE := TRUE;
           IF SRCPOS >= G16 THEN T29;
           IF (SRCWIN[SRCPOS] = CHR(16)) AND NOT INMACDEF THEN
             BEGIN
               ASMCH := ORD(SRCWIN[SRCPOS + 1]);
               DLEZERO := ASMCH - 32 = 0;
               SRCPOS := SRCPOS + 2
             END;
           ASMCH := ORD(SRCWIN[SRCPOS]);
           IF (ASMCH = 59) AND FOLDCAS THEN
             BEGIN
               V1 := SCAN(102, = CHR(13), SRCWIN[SRCPOS]);
               SRCPOS := SRCPOS + V1;
               ASMCH := 13
             END
           ELSE IF (ASMCH = 32) AND FOLDCAS AND NOT INMACDEF THEN
             BEGIN
               V1 := SCAN(102, <> ' ', SRCWIN[SRCPOS]);
               SRCPOS := SRCPOS + V1 - 1
             END
           ELSE IF ASMCH <> 13 THEN
             IF ASMCH = 9 THEN ASMCH := 32
         END
    END;
    IF (ASMCH IN [97..122]) AND FOLDCAS THEN ASMCH := ASMCH - 32
  END;

  { Remainder done by hand for the cases MOD will not serve: X1 MOD X2
    when both are non-negative, and an explicit fold through
    4 * (16384 MOD X2) when X1 is negative -- 65536 MOD X2 built out of
    a constant that fits in sixteen bits. One local word. }
  FUNCTION T20;                               { .20  8/2 }
    VAR
      V5: INTEGER;
  BEGIN
    IF X2 >= 0 THEN
      BEGIN
        IF X1 >= 0 THEN T20 := X1 MOD X2
        ELSE
          BEGIN
            V5 := 4 * (16384 MOD X2) MOD X2;
            T20 := X2 - (-X1 - V5) MOD X2
          END
      END
    ELSE
      IF X1 >= X2 THEN T20 := X1 - X2
      ELSE T20 := X1
  END;

  { Validates the operand just parsed: the right class, inside the
    caller's bounds, and no forward reference where one is not allowed.
    No locals at all -- the result word is the only thing it writes. }
  FUNCTION T19;                               { .19  14/0 }
  BEGIN
    IF X2 AND NOT (EXPRVAL IN [0, 22, 23, 24, 25, 34]) AND G63 THEN
      BEGIN
        T2(24);
        T19 := FALSE
      END
    ELSE IF X3 AND ((EXPRCLS < X4) OR (EXPRCLS > X5)) THEN
      BEGIN
        T2(2);
        T19 := FALSE
      END
    ELSE IF X1 AND (SPCLSTIX <> -1) THEN
      BEGIN
        T2(25);
        SPCLSTIX := -1;
        T19 := TRUE
      END
    ELSE T19 := TRUE
  END;

  { The expression evaluator. 44 declared local words and two temps:
    the WITH slot its own body opens over STK, and a FOR limit holding
    LENGTH of the operand string. STK is 21 two-word entries, which is
    what `LDA 1,6 | IXA 2` in both children measures, and STKINDEX is
    the one they index it with.

    STACKTYPE's one-bit FILL is real: TIPE is seven bits at 0 and ATRIB
    eight bits at 8, and with nothing between them the compiler would
    have put ATRIB at bit 7. }
  FUNCTION EXPRESS;                               { .18  6/92 }
    TYPE
      STACKTYPE = PACKED RECORD
                    TIPE: 0..127;
                    FILL: 0..1;
                    ATRIB: 0..255;
                    VALUE: INTEGER
                  END;
    VAR
      STKINDEX, COUNT: INTEGER;
      STK: ARRAY [0..20] OF STACKTYPE;

    PROCEDURE EXPREXIT;                            { .31  0/0 }
    BEGIN
      T2(26);
      WHILE LEXTOKEN <> 38 DO T17;
      EXPRESS := FALSE;
      EXIT(EXPRESS)
    END;

    { Decides what the finished stack means. Nothing left is either an
      empty expression or a missing operand; one NULL entry is a plain
      value; a NULL under a PLUS, MINUS or ASTERISK is the
      autoincrement/autodecrement form, and the operator goes on the
      special stack for the caller to read. EXPRCLS and EXPRVAL are the value
      and attribute it returns, and RELOCATE's words 3 and 4 the copy the
      relocation record keeps. }
    PROCEDURE EXPREND;                            { .32  0/0 }
    BEGIN
      IF LEXTOKEN IN [0, 1, 8] THEN
        BEGIN
          SPCLSTIX := SPCLSTIX + 1;
          SPECSTK[SPCLSTIX] := LEXTOKEN
        END;
      IF STKINDEX = -1 THEN
        IF LEXTOKEN = 8 THEN
          BEGIN
            EXPRESS := FALSE;
            EXIT(EXPRESS)
          END
        ELSE IF X1 THEN
          BEGIN
            T2(27);
            EXPRESS := FALSE
          END
        ELSE EXPRESS := FALSE
      ELSE IF (STKINDEX = 0) AND (STK[STKINDEX].TIPE = 70) THEN
        BEGIN
          EXPRCLS := STK[STKINDEX].VALUE;
          EXPRVAL := STK[STKINDEX].ATRIB;
          RELOCATE.W4 := EXPRVAL;
          RELOCATE.W3 := EXPRCLS;
          EXPRESS := TRUE
        END
      ELSE IF (STKINDEX = 1) AND (STK[0].TIPE = 70)
              AND (STK[STKINDEX].TIPE IN [18, 19, 20]) THEN
        BEGIN
          SPCLSTIX := SPCLSTIX + 1;
          CASE STK[STKINDEX].TIPE OF
            18: SPECSTK[SPCLSTIX] := 25;
            19: SPECSTK[SPCLSTIX] := 26;
            20: SPECSTK[SPCLSTIX] := LEXTOKEN
          END;
          EXPRCLS := STK[0].VALUE;
          EXPRVAL := STK[0].ATRIB;
          RELOCATE.W4 := EXPRVAL;
          RELOCATE.W3 := EXPRCLS;
          EXPRESS := TRUE
        END
      ELSE EXPRESS := FALSE;
      EXIT(EXPRESS)
    END;

    { Folds the top three stack entries -- operand, operator, operand --
      into one, or a unary operator into its operand. I.5's OPERFOLD
      with Apple's changes: the two early EXITs are one guard, local 6
      decides binary against unary, and an assembly that is not
      relocatable (neither G63 nor RELOCATE.W1) treats every pair as
      absolute. Attribute 34 is ABS; 0 and 22..25 are the other absolute
      classes. The arms are in I.5's order, which is physical order.

      Frame: I.5's LATTRIBUTE, RATTRIBUTE reverses to 2 and 1, then
      KLUDGETYPE, RVALUE and BOTHABSOLUTE at 3..5, Apple's local 6, and
      the WITH slot at 7 that both WITHs use. }
    PROCEDURE OPERFOLD;                            { .33  0/14 }
      VAR
        LATTRIBUTE, RATTRIBUTE: INTEGER;
        KLUDGETYPE: INTEGER;
        RVALUE: INTEGER;
        BOTHABSOLUTE: BOOLEAN;
        V6: BOOLEAN;
    BEGIN
      IF STK[STKINDEX - 1].TIPE <> 15 THEN
        BEGIN
          IF STKINDEX >= 2 THEN V6 := STK[STKINDEX - 2].TIPE <> 15
          ELSE V6 := FALSE;
          IF V6 THEN
            IF STK[STKINDEX - 2].TIPE = 70 THEN
              BEGIN
                LATTRIBUTE := STK[STKINDEX - 2].ATRIB;
                RATTRIBUTE := STK[STKINDEX].ATRIB;
                IF LATTRIBUTE IN [0, 22, 23, 24, 25] THEN LATTRIBUTE := 34;
                IF RATTRIBUTE IN [0, 22, 23, 24, 25] THEN RATTRIBUTE := 34;
                BOTHABSOLUTE := ((LATTRIBUTE = 34) AND (RATTRIBUTE = 34))
                                OR NOT (G63 OR RELOCATE.W1);
                RVALUE := STK[STKINDEX].VALUE;
                KLUDGETYPE := STK[STKINDEX - 1].TIPE;
                WITH STK[STKINDEX - 2] DO
                  IF NOT (KLUDGETYPE IN [2, 3, 4, 5, 18, 19, 20, 21]) THEN
                    EXPREXIT
                  ELSE
                    CASE KLUDGETYPE OF
                      18: IF (LATTRIBUTE = 34) OR (RATTRIBUTE = 34) THEN
                            BEGIN
                              VALUE := VALUE + RVALUE;
                              IF RATTRIBUTE <> 34 THEN ATRIB := RATTRIBUTE
                            END
                          ELSE EXPREXIT;
                      19: IF (RATTRIBUTE = 34) OR ((RATTRIBUTE <> 34) AND
                             (LATTRIBUTE = RATTRIBUTE)) THEN
                            BEGIN
                              VALUE := VALUE - RVALUE;
                              IF RATTRIBUTE <> 34 THEN ATRIB := 34
                            END
                          ELSE EXPREXIT;
                      2: IF BOTHABSOLUTE THEN
                           VALUE := ORD(ODD(VALUE) OR ODD(RVALUE))
                         ELSE EXPREXIT;
                      21: IF BOTHABSOLUTE THEN
                            VALUE := ORD(ODD(VALUE) AND ODD(RVALUE))
                          ELSE EXPREXIT;
                      3: IF BOTHABSOLUTE THEN
                           VALUE := ORD((ODD(VALUE) AND NOT ODD(RVALUE)) OR
                                        (NOT ODD(VALUE) AND ODD(RVALUE)))
                         ELSE EXPREXIT;
                      20: IF BOTHABSOLUTE THEN VALUE := VALUE * RVALUE
                          ELSE EXPREXIT;
                      4: IF BOTHABSOLUTE THEN VALUE := VALUE DIV RVALUE
                         ELSE EXPREXIT;
                      5: IF BOTHABSOLUTE THEN VALUE := VALUE MOD RVALUE
                         ELSE EXPREXIT
                    END;
                STKINDEX := STKINDEX - 2
              END
            ELSE EXPREXIT
          ELSE IF STK[STKINDEX].ATRIB = 34 THEN
            WITH STK[STKINDEX - 1] DO
              BEGIN
                CASE TIPE OF
                  19: VALUE := -STK[STKINDEX].VALUE;
                  18: VALUE := STK[STKINDEX].VALUE;
                  6: VALUE := -STK[STKINDEX].VALUE - 1
                END;
                STKINDEX := STKINDEX - 1;
                TIPE := 70;
                ATRIB := 34
              END
          ELSE EXPREXIT
        END
    END;

  { EXPRESS's own body: a loop that pushes operands and operators and
    folds as it goes, and never falls out -- its three children set the
    result and EXIT. I.5's with Apple's changes: the CASE runs inside
    WITH STK[STKINDEX + 1], so an arm can bump STKINDEX and still write
    the entry it was about to fill; a full stack is error 26 and out of
    the assembler; every OPERFOLD waits until there are two entries; and
    token 46 (.INTERP, finding 256a) gets an arm of its own. The IN set
    is exactly the union of the CASE labels. }
  BEGIN
    RELOCATE := G598;
    STKINDEX := -1;
    REPEAT
      IF EXPRADV THEN T17
      ELSE EXPRADV := TRUE;
      IF NOT (LEXTOKEN IN [0..9, 14, 15, 16, 18..22, 24..27, 38, 46,
                           65..68]) THEN EXPREXIT
      ELSE IF STKINDEX >= 20 THEN
        BEGIN
          T2(26);
          T21;
          EXIT(TLA)
        END
      ELSE
        WITH STK[STKINDEX + 1] DO
          CASE LEXTOKEN OF
            2, 3, 4, 5, 6, 15, 18, 19, 21:
              BEGIN
                STKINDEX := STKINDEX + 1;
                TIPE := LEXTOKEN
              END;
            20: IF STKINDEX = -1 THEN
                  IF LCCHAR = '*' THEN
                    BEGIN
                      STKINDEX := STKINDEX + 1;
                      IF G660 = 0 THEN VALUE := G21
                      ELSE VALUE := G20;
                      RELOCATE.W0 := 3;
                      ATRIB := 35;
                      TIPE := 70;
                      IF STKINDEX > 0 THEN OPERFOLD
                    END
                  ELSE
                    BEGIN
                      SPCLSTIX := SPCLSTIX + 1;
                      SPECSTK[SPCLSTIX] := LEXTOKEN
                    END
                ELSE
                  BEGIN
                    STKINDEX := STKINDEX + 1;
                    TIPE := LEXTOKEN
                  END;
            27: BEGIN
                  STKINDEX := STKINDEX + 1;
                  IF G660 = 0 THEN VALUE := G21
                  ELSE VALUE := G20;
                  IF RELOCATE = G598 THEN RELOCATE.W0 := 3
                  ELSE IF RELOCATE.W0 = 3 THEN RELOCATE := G598;
                  ATRIB := 35;
                  TIPE := 70;
                  IF STKINDEX > 0 THEN OPERFOLD
                END;
            66, 67:
              BEGIN
                STKINDEX := STKINDEX + 1;
                VALUE := 0;
                IF LEXTOKEN = 67 THEN VALUE := NUMVAL
                ELSE IF LENGTH(STRCONST) <= 2 THEN
                  FOR COUNT := 1 TO LENGTH(STRCONST) DO
                    VALUE := VALUE * 256 + ORD(STRCONST[COUNT])
                ELSE EXPREXIT;
                ATRIB := 34;
                TIPE := 70;
                IF STKINDEX > 0 THEN OPERFOLD
              END;
            65: BEGIN
                  IF RELOCATE.W1 THEN
                    BEGIN
                      IF G691[LOCLCUR].LCLASS = 36 THEN T2(28)
                    END
                  ELSE
                    BEGIN
                      IF G691[LOCLCUR].LCLASS = 36 THEN RELOCATE.W1 := TRUE;
                      RELOCATE.W0 := 0;
                      RELOCATE.W2 := LOCLCUR
                    END;
                  STKINDEX := STKINDEX + 1;
